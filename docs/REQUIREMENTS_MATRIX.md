# 요구사항 검토표

## 2026-11-11 1차 검토 추가 범위

아래 항목은 기존 기획/agent 기능에 추가한 검토 API다. 운영 Next.js 화면이나 실제 모델 정확도 완료를 뜻하지 않는다.

| 추가 기능 | 판정 | 통합 경로·한계 |
|---|---|---|
| 사례 전 사용자별 검토 초안·다중 자료 | API 구현 | review_sessions/review_documents, 인증·revision·이력·재시작 보존 |
| 자동 처리 선택·혼합 PDF 구간 분류 | API 구현 | 명시적 auto_process/auto_verify, 구간 중복·불명확 경계 검증 |
| 원문 페이지·필드 좌표·행별 검토 | API 구현 | 실제 PNG·정규화 좌표와 불확실 상태, 각 칸 별도 저장·확정 |
| 제한된 원문 이미지 재검증 | API 구현 | 구간별 최대50항목/6페이지, 별도 후보·사용자 확인 유지. 기존 B와 별개 |
| 충돌 개별 확정·확인값 계산 연결 | API 구현 | source_seen/현재 충돌ID, 사용자확인만 스냅샷에 반영, 기존 run_task |
| 취소·중단·재개·사용량 | API 구현 | DB 실행권·해시·완료 응답 캐시·누적 예산, 공통 동시 실행 제한 |
| AI 추천·검토 안내 채팅 | 후속 범위 | 기존 자유 채팅 유지. 새 추천/검토 챗봇 실행 경로 없음 |
| 검토 화면·실행 그래프 UI | 후속 범위 | 별도 Next.js 개발 필요. 모델/도구 실행 기록 API는 제공 |

원본/파생 PDF 및 ZIP 출처 기록, 공개 계약1.1과 기존1.0 호환을 유지한다. 전체733통과/9skip의 검증 범위는 `VERIFICATION.md`를 참조한다. 아래 표는 통합본의 기존 검토 이력이다.

기준: 루트 `월급잇다_기획명세서_v1.0.md`와 원본 `agent/README.md` 두 문서. 다른 문서에서 추가 요구사항을 가져오지 않았다. **구현 완료**는 통합 실행 경로와 명시된 테스트가 확인되었다는 뜻이며 실제 모델·OCR 정확성, 법률 검증, Next.js 화면 검증을 뜻하지 않는다. **부분 구현**은 지원 또는 운영 범위가 제한된 경우, **미구현**은 실행 경로가 없는 경우, **미검증**은 실제 실행 증거가 없는 경우다.

## agent README의 지원 기능 연결

| 항목 | 판정 | 근거/제한 |
|---|---|---|
| Python3.14·공통 의존성 | 구현 완료 | pyproject.toml/uv.lock, Python3.14.4 전체 회귀. 독립 복사 실행은 VERIFICATION 별도 기록. |
| recognize_document 별도 읽기 | 구현 완료 | read_document는 backend 작업, A/B는 agent extract_document. OCR ID·페이지/방식/해시 실제 저장. |
| 텍스트 추출 A | 구현 완료 | 저장 OCR만 재사용·run_task 직접 호출·업로드 자동 AI 없음. document scope case_id=null 공개 schema1.1; 이전1.0 호환. |
| PDF 보완 B | 구현 완료 | 별도 작업·대상1~50·OCR/A/원본 계보·A 불변·B 별도 후보·자동 확인 없음 테스트. 외부 모델은 대역. |
| 항목별 정규화·근거 | 구현 완료 | raw/suggested/normalized·검증 상태/사유 보존, saved evidence 위조 차단, 기존 agent 회귀. valid도 사용자 확인 필요. |
| 독립 비교 묶음 | 구현 완료 | group_materials·confirmed-input·묶음별 버전/이력·재확인. 대상 충돌을 포괄 확인으로 무시하지 않음. |
| 표준 W-01~05/R-07 | 부분 구현 | README 표준 시급/월급 범위 실제 DB 저장 검증; 지원 밖 조건은 미완료 표시. |
| 정보 부족의 부분 검사 | 구현 완료 | gross_total=null·항목별 상태·가능한 명세서 검사 유지 테스트. |
| 설명·질문·문의·용어 | 구현 완료 | 기본 템플릿 및 용어 API. 설명/문의는 외부 모델 없이 실제 실행. |
| PDF/ZIP | 구현 완료 | 고정 결과/입력·번들 한글 폰트·파일 hash·권한 검증. 이미지 원본 바이트와 파생PDF 계보를 ZIP에 보존하는 통합 테스트 통과. |
| 체크포인트·누적 예산·재시작 | 구현 완료 | 실제 DB: 모델 실패3회 후 재시도 추가 호출0, 새 run_id fencing, 중복 결과1개. |
| 취소·접근·원본 무결성 | 구현 완료 | 실행/최종 확정/다운로드 재검사. 취소·삭제·연결철회·소유권철회·실행권 상실 저장 거절. 실제 파일 변조 후 확정 차단, 재연결로 이전 접근권이 복원되지 않는 회귀 통과. |
| 운영 AgentPorts | 구현 완료 | DatabaseAgentPorts SQLite/파일. app에서 agent.dev·LocalFilePorts·owner-local·내부HTTP URL 의존 없음. |
| 개발 화면·LocalStore | 범위 제외 | agent/dev는 기존 개발 회귀용. 운영 프론트로 연결하지 않음. |
| 실제 모델·스캔 OCR 품질 | 미검증 | 공급자/OCR 대역 성공을 실제 판독 품질 검증으로 표현하지 않음. |
