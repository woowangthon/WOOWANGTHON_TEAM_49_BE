## 기본 읽기 A·선택 PDF 보완 B — 2026-11-08

- 기본 원문 읽기는 페이지마다 품질 조건을 통과한 디지털 PDF 텍스트를 배치 정보와 함께 먼저 사용한다. 이미지가 있는 페이지, 숨은 문자·투명 문자·낮은 대비·도형 가림·깨진 글꼴·누락이 의심되는 페이지는 기존 로컬 OCR로 읽는다. 혼합 PDF는 페이지별 경로를 보존하며 숫자 구두점이나 단위를 임의로 고치지 않는다. 이는 보수적인 선별 검사이며 모든 렌더링 형태의 가시성을 보증하지 않는다.
- A는 저장된 원문 읽기 결과의 텍스트만 AI에 보내 유형·항목·표를 정리한다. `source_method=pdf_text / python_ocr / mixed`, `page_methods`와 페이지별 텍스트를 보존한다. 디지털 텍스트에는 OCR 신뢰도 점수를 만들어 넣지 않는다.
- B는 A의 `needs_review / missing` 항목 가운데 사용자가 선택한 1~50개만 대상으로 별도 실행한다. **원본 전체 PDF를 OpenAI에 전송하는 추가 유료 요청**이며 선택 항목만 전달되는 문서 자르기 기능은 아니다. 기본 읽기와 A 분류에 성공한 자료에서 실행하며 자동 재호출·자동 보완은 하지 않는다.
- 기본 후보 `extraction_a`, `extraction_a_revision`, `extraction_a_context`, B 실행별 `supplements`, 사용자 선택 `candidate_selections`와 무효화 이력 `candidate_selection_history`를 구분해 저장한다. B 완료는 A나 확인값을 바꾸지 않는다. 사용자가 원문을 확인한 뒤 검사 통과 후보를 선택하거나 직접 수정하고, 판단이 어려우면 보류한다.
- `text_match`는 PDF 텍스트층과의 일치, `ocr_unverified`는 OCR 텍스트 근거, `vision_unverified`는 B 판독 근거를 뜻한다. 어느 것도 원본 내용의 사실성·시각적 정확성·사용자 확인 완료를 뜻하지 않으며 A/B 일치도 확인을 대체하지 않는다.
- B에도 값 범위·단위·형식과 같은 항목 검사를 적용한다. 불명확한 금액 구두점은 정상 숫자로 조용히 바꾸지 않으며 표의 다른 행을 같은 항목으로 적용하지 못하게 문맥을 검사한다. 판독 불가·미기재 값은 null로 남기고 누락값을 계산해 채우지 않는다.
- 후보 선택은 A 버전·원본 해시·원문 읽기 ID를 확인하고 유효한 근거 및 사용자의 원문 확인을 요구한다. 선택 후 확인 입력과 의존 비교 결과는 재확인 대상으로 갱신한다. 원문 재읽기·재추출·유형 변경은 현재 A/B 연결을 무효화하고 이력은 보존한다. 기존 저장 자료는 자동 재실행하지 않는다.
- 추출 계약 기본값은 `extraction_version=1.2`이며 `extraction_method=text / pdf_supplement`, `target_fields`와 읽기 경로 메타데이터를 추가했다. 엔진 `agent-0.3.0`, 공개 스키마·체크포인트 `1.0`을 유지하고 기존 입력·저장 자료 호환을 유지한다.
- 취소·중단·재시작에도 동일 논리 작업의 호출 횟수와 사용량 예산을 이어받는다. 이미 전송된 요청은 취소해도 사용량이 발생할 수 있으며 취소 뒤 도착한 후보를 적용하지 않는다.

- 실행 중 작업 0개를 확인한 뒤 로컬 4190 서버를 갱신했다. 상태 응답의 `extraction_pipeline=text_first_with_pdf_supplement`, 기존 문서 10개·AI 처리 자료 5개·사용 중 비교 묶음 조회를 확인했다. 기존 저장 파일 **50개 SHA-256 일치**로 원본·처리 자료 보존을 확인했으며 기존 자료를 자동 재읽기·재추출하지 않았다.

- 추출 검토 계약을 `extraction_version=1.1`로 구분한다. 엔진 `agent-0.3.0`, 공개 스키마·체크포인트 `1.0`은 유지하고 `1.0` 추출 입력도 지원한다. 기존 검사에 성공한 저장 결과는 호환 목적으로 `valid` 기본값을 적용하며 사용자 확인은 계속 필요하다. 이번 항목별 검토는 새 추출에 적용하고 과거 저장 결과를 일괄 재검증하거나 무효화하지 않는다.

- 한 항목의 인용·페이지·숫자·단위·날짜·표 행 오류는 해당 후보를 검토 필요로 남긴다. 정상 항목을 함께 보존하고 항목 오류로 전체 추출을 실패시키거나 AI를 자동 재호출하지 않는다. 문서 유형·응답 구조·권한·해시·저장 OCR 연결 등 전체 실행 조건의 실패는 유지한다.
